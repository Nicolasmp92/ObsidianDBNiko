# 🌍 Wiki — Localización (Lang) en Laravel

## 📌 1. ¿Qué es `lang` y por qué importa?

Laravel utiliza un sistema de **Localización (i18n)** que desacopla el contenido de la interfaz del código duro.

- **Propósito:** Permitir que tu app "hable" varios idiomas (inglés, español, etc.) cambiando una sola variable de configuración.
    
- **Funcionamiento:** En lugar de escribir `<h1>Bienvenido</h1>`, usas un puntero `{{ __('Welcome') }}`. Laravel busca ese puntero en archivos JSON o PHP dentro de `resources/lang/` y devuelve el texto traducido.
    

---

## 📌 2. Instalación y Preparación

Instala los paquetes necesarios para gestionar las traducciones de forma profesional:

Bash

```
# Paquetes base y utilidades de publicación
composer require laravel-lang/common laravel-lang/http-statuses laravel-lang/publisher
```

Luego, añade los idiomas que tu proyecto necesite:

Bash

```
php artisan lang:add es  # Español
php artisan lang:add en  # Inglés (Fallback)
php artisan lang:publish # Genera los archivos en resources/lang/
```

---

## 📌 3. Configuración Maestra

Configura tu entorno para que sea flexible. Esto es clave para el orden de tu **StarterCustomeKit**.

### En el `.env`

Fragmento de código

```
APP_LOCALE=es
APP_FALLBACK_LOCALE=en
APP_FAKER_LOCALE=es_ES
```

### En `config/app.php`

PHP

```
'locale'          => env('APP_LOCALE', 'es'),
'fallback_locale' => env('APP_FALLBACK_LOCALE', 'en'),
'faker_locale'    => env('APP_FAKER_LOCALE', 'es_CL'), // Localizado para Chile 🇨🇱
'timezone'        => 'America/Santiago',
```

> **Nota:** El `fallback_locale` es tu red de seguridad: si una traducción no existe en español, Laravel mostrará la versión en inglés en lugar de un código vacío.

---

## 📌 4. Implementación y Estructura

Existen dos formas de organizar tus traducciones en `resources/lang/`:

1. **Archivos PHP (Tradicional):** Ideal para textos cortos del sistema.
    
    - _Archivo:_ `resources/lang/es/auth.php`
        
    - _Contenido:_ `return ['failed' => 'Credenciales incorrectas.'];`
        
    - _Uso:_ `{{ __('auth.failed') }}`
        
2. **Archivos JSON (Moderno):** Ideal para frases largas o aplicaciones SPA.
    
    - _Archivo:_ `resources/lang/es.json`
        
    - _Contenido:_ `{"Welcome": "Bienvenido"}`
        
    - _Uso:_ `{{ __('Welcome') }}`
        

---

## 📌 5. Mantenimiento Rápido

Si editas los archivos y no ves los cambios, limpia la caché de inmediato:

Bash

```
php artisan config:clear && php artisan cache:clear
```
