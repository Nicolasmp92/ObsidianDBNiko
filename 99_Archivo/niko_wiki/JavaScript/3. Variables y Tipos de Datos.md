# 📦 Variables y Tipos de Datos

## Declaración: `const`, `let` y `var`

```javascript
const nombre = "Niko";   // no se puede reasignar — úsala por defecto
let contador = 0;        // sí se puede reasignar
var viejo = "evítalo";   // scope de función + hoisting confuso
```

> [!TIP] Regla rápida
> **`const` siempre, `let` si cambia, `var` nunca.** Así tu código es predecible y evitas bugs de reasignación accidental.

## Tipos primitivos

| Tipo | Ejemplo | `typeof` devuelve |
|---|---|---|
| `string` | `"hola"`, `'texto'` | `"string"` |
| `number` | `42`, `3.14` | `"number"` |
| `bigint` | `9007199254740991n` | `"bigint"` |
| `boolean` | `true`, `false` | `"boolean"` |
| `undefined` | variable sin asignar | `"undefined"` |
| `null` | ausencia intencional de valor | `"object"` ⚠️ (bug histórico de JS) |
| `symbol` | `Symbol("id")` | `"symbol"` |

Todo lo demás (objetos, arrays, funciones) es tipo **object**.

## Template literals

Con backticks puedes interpolar variables y escribir multilínea:

```javascript
const saludo = `Hola ${nombre}, tienes ${2026 - 1995} años`;
```

## Conversión y truthy/falsy

```javascript
Number("42");   // 42
String(42);     // "42"
Boolean("");    // false
```

Valores **falsy** (se evalúan como `false`): `0`, `""`, `null`, `undefined`, `NaN`, `false`.  
Todo lo demás es **truthy** — ojo: `"0"` y `[]` son truthy.

> [!WARNING] `==` vs `===`
> `==` convierte tipos antes de comparar (`"5" == 5` → true). Usa siempre **`===`** (comparación estricta, sin conversión) para evitar sorpresas.
