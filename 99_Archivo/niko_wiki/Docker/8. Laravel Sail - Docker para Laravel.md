# ⛵ Laravel Sail: Docker para Laravel

**Sail** es el entorno de desarrollo oficial de Laravel, construido sobre Docker Compose. Te da PHP, MySQL, Redis y más sin escribir un solo Dockerfile — ideal para arrancar rápido.

## Instalación

```bash
# En un proyecto Laravel existente:
composer require laravel/sail --dev
php artisan sail:install        # eliges los servicios (mysql, redis, etc.)
./vendor/bin/sail up -d         # levanta el entorno
```

> [!TIP] Alias para no escribir la ruta completa
> ```bash
> alias sail='./vendor/bin/sail'
> ```
> Después de esto usas directamente `sail up -d`, `sail artisan`, etc.

## Comandos Sail = tus comandos de siempre

| En vez de... | Con Sail |
|---|---|
| `php artisan migrate` | `sail artisan migrate` |
| `composer install` | `sail composer install` |
| `npm run dev` | `sail npm run dev` |
| `phpunit` | `sail test` |
| Entrar al contenedor | `sail shell` / `sail bash` |

Internamente Sail usa `docker-compose.yml` (lo genera en tu repo) — todo lo aprendido en [[6. Docker Compose - Orquestar Contenedores|Docker Compose]] aplica igual.

## ¿Sail o Docker a mano?

| Contexto | Recomendación |
|---|---|
| Arrancar un proyecto Laravel rápido | **Sail** |
| Onboarding de un dev nuevo | **Sail** (cero fricción) |
| Stack custom (extensiones raras, servicios especiales) | **Dockerfile + Compose propio** (notas [[5. Dockerfile - Construir Imágenes Propias|5]] y [[6. Docker Compose - Orquestar Contenedores|6]]) |
| StarterCustomeKit como base reutilizable | Evaluar Sail como dev-environment estándar del kit |
