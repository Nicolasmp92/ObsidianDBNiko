🧭 ¿Qué es Docker?

Plataforma que empaqueta aplicaciones con todas sus dependencias en **contenedores** estandarizados: mismo comportamiento en tu PC, en el servidor de pruebas y en producción.

Para los conceptos base (imagen, contenedor, Dockerfile, Docker Hub) y la analogía del barco:  
👉 **[[2. Introducción a Docker]]**

💻 El Entorno

Docker rinde mal si trabajas desde Windows con archivos en `C:\`. La forma correcta es desde Linux (WSL2) con VS Code integrado.
