# 🅰️ 3. Primer Proyecto y Comandos Esenciales

## Crear el proyecto

```bash
ng new mi-app
# Preguntas del CLI:
#   Stylesheet format?  → CSS          (Tailwind va sobre CSS plano, no SCSS)
#   SSR/SSG?            → Yes          (los estándares usan SSR con Express 5)
```

O directo con flags:

```bash
ng new mi-app --style=css --ssr --routing
cd mi-app
```

Esto genera el proyecto **standalone por defecto** (sin `NgModules`) — tal como pide el stack.

## Levantar y construir

```bash
npm start          # ng serve → http://localhost:4200
npm run build      # ng build → dist/
npm test           # tests (Vitest si el proyecto lo trae configurado)
npx ng lint        # eslint con angular-eslint
```

## Comandos esenciales del CLI

| Comando | Genera |
|---|---|
| `ng g c features/users/user-list` | Componente standalone (`.ts` + `.html` + `.css` + spec) |
| `ng g s core/services/auth` | Servicio inyectable |
| `ng g guard core/guards/auth` | Guard de ruta |
| `ng g interceptor core/interceptors/auth` | Interceptor HTTP |
| `ng g pipe shared/pipes/truncate` | Pipe |
| `ng g directive shared/directives/tooltip` | Directiva |
| `ng generate environments` | `environment.ts` / `environment.development.ts` |

> [!TIP] Dry run
> `ng g c nombre --dry-run` muestra qué archivos crearía sin crearlos.

## Estructura que sigue este vault (Screaming Architecture)

```
src/app/
├── core/       # singletons: servicios, guards, interceptors, config
├── shared/     # UI "dumb": componentes, pipes, directivas, models/
└── features/   # una carpeta por módulo de negocio
```

Detalle completo en [[Estándares Front-End - Angular]].

## Próximos pasos

- Tailwind CSS 4: `npm install tailwindcss @tailwindcss/postcss postcss` y `@import "tailwindcss";` en `src/styles.css`.
- Angular CDK para componentes complejos headless: `npm install @angular/cdk`.
- Routing lazy por feature: `loadComponent` / `loadChildren`.
