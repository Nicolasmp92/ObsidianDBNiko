# ☕ 3. Spring Boot — Crear una API REST

## 1. Generar el proyecto — Spring Initializr

En https://start.spring.io (o desde VS Code con el Spring Boot Extension Pack):

| Campo | Valor típico |
|---|---|
| Project | Maven |
| Language | Java |
| Spring Boot | última estable 3.x |
| Packaging | Jar |
| Java | 21 |

**Dependencias mínimas para una API REST:**
- `Spring Web` — `@RestController`, servidor embebido (Tomcat)
- `Spring Data JPA` — si hay base de datos
- `Validation` — `@Valid` en DTOs
- Driver de tu BD: `PostgreSQL Driver` / `MySQL Driver`
- `Spring Boot DevTools` — hot reload en desarrollo

Descargar el ZIP, extraer y abrir la carpeta en VS Code.

## 2. Estructura generada

```
src/main/java/com/example/demo/
├── DemoApplication.java        # @SpringBootApplication — entrypoint
├── controller/                 # @RestController — endpoints
├── service/                    # lógica de negocio
├── repository/                 # interfaces JPA
└── model/                      # entidades y DTOs
src/main/resources/
└── application.properties      # config (puerto, datasource, etc.)
```

## 3. Endpoint mínimo

```java
@RestController
@RequestMapping("/api/tasks")
public class TaskController {

    @GetMapping
    public List<Task> all() {
        return taskRepository.findAll();
    }

    @PostMapping
    public ResponseEntity<Task> create(@Valid @RequestBody Task task) {
        return ResponseEntity.status(HttpStatus.CREATED)
                             .body(taskRepository.save(task));
    }
}
```

El mapping de verbos/códigos sigue lo visto en [[4. Verbos HTTP en APIs REST]] y [[5. Códigos de Estado HTTP]].

## 4. Correr

```bash
./mvnw spring-boot:run     # wrapper Maven incluido, no requiere Maven instalado
# → http://localhost:8080/api/tasks
```

| Comando | Acción |
|---|---|
| `./mvnw spring-boot:run` | Levantar en desarrollo |
| `./mvnw test` | Correr tests (JUnit + MockMvc) |
| `./mvnw package` | Generar `target/*.jar` ejecutable |
| `java -jar target/demo-0.0.1-SNAPSHOT.jar` | Correr el jar |

## 5. `application.properties` típico

```properties
server.port=8080
spring.datasource.url=jdbc:postgresql://localhost:5432/midb
spring.datasource.username=user
spring.datasource.password=pass
spring.jpa.hibernate.ddl-auto=validate
```

> [!WARNING] Credenciales
> Nunca commitear passwords reales — usar variables de entorno o `.env` excluido del repo (igual que en los estándares front).

## 🔗 Conectar con el front

El front [[1. Index Angular|Angular]] consumirá esta API con `HttpClient` — recuerda habilitar **CORS** para `http://localhost:4200` (`@CrossOrigin` o config global `WebMvcConfigurer`).
