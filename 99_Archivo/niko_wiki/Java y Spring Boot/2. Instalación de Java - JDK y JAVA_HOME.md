# ☕ 2. Instalación de Java — JDK y JAVA_HOME

Spring Boot 3.x requiere **Java 17+**; recomendado **JDK 21 LTS**.

## 1. Instalar el JDK

### Ubuntu / WSL2 (apt)

```bash
sudo apt update
sudo apt install openjdk-21-jdk
```

### SDKMAN (recomendado — maneja versiones y también instala Maven/Gradle)

```bash
curl -s "https://get.sdkman.io" | bash
# cerrar y reabrir la terminal, luego:
sdk install java 21.0.5-tem
sdk install maven
```

`sdk list java` muestra todas las versiones disponibles; `sdk use java <versión>` cambia solo en la terminal actual, `sdk default java <versión>` lo fija global.

## 2. Verificar

```bash
java --version    # openjdk 21.x
javac --version   # el compilador — si falta, instalaste un JRE, no un JDK
```

## 3. JAVA_HOME

Muchas herramientas (Maven, algunos servidores) leen `JAVA_HOME`. Con apt suele resolverse solo; con SDKMAN ya viene configurado. Manual:

```bash
# saber dónde quedó:
readlink -f $(which java)
# exportar en ~/.bashrc:
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64
```

## ⚠️ Errores típicos

| Error | Causa | Fix |
|---|---|---|
| `javac: command not found` | Instalaste `openjdk-21-jre` (solo runtime) | `sudo apt install openjdk-21-jdk` |
| `Unsupported class file major version` | Compilado con un JDK más nuevo que el runtime | Alinear `java` y `javac` a la misma versión |
| Maven usa otro Java | `JAVA_HOME` apunta a otra versión | `mvn -version` muestra qué JDK usa |
