### 🟤 Objetivo del Stack

Configurar desde cero un proyecto **Laravel 12** con las siguientes características:

- ✅ Laravel Installer v5+
- ✅ **Breeze + Livewire Stack**
- ✅ Autenticación integrada
- ✅ Tailwind CSS
- ✅ Vite como bundler
- ✅ Testing con PHPUnit
- ✅ Repositorio Git inicializado
- ✅ Layouts y componentes base limpios, listos para extender


| Característica | Elección           | Beneficio                                    |
| -------------- | ------------------ | -------------------------------------------- |
| Auth           | Breeze + Livewire  | Base sólida y profesional.                   |
| Componentes    | Single-file (Volt) | Todo en un archivo; orden absoluto..         |
| Testing        | PHPUnit            | El estándar de oro para estabilidad.         |
| IA Ready       | Laravel Boost      | Optimizado para que trabajemos juntos mejor. |
|                |                    |                                              |

### 📁 Estructura inicial del proyecto

`StarterCustomeKit/ 

---

### 🧪 Pasos para crear el proyecto

#### 1️⃣ Instalar Laravel Installer v5+

```
composer global require laravel/installer
```
---

#### 2️⃣ Crear el proyecto base con Breeze (Stack Blade)

> **Nota:** El flag `--stack=livewire` aún no está disponible directamente.  
> Se instala primero Breeze (Blade), y luego se transforma a Livewire.

```
cd C:\xampp\htdocs 
laravel new StarterCustomeKit

>livewire
>laravel
>
```
---

#### 3️⃣ Entrar al proyecto

`cd StarterCustomeKit`

---

#### 4️⃣ Instalar Livewire sobre Breeze

```
cd my-app
npm install && npm run build
composer run dev
```
---

#### 5️⃣ Instalar dependencias front-end y compilar assets

`npm install npm run dev`

---

#### 6️⃣ Ejecutar migraciones

`php artisan migrate`

### 💡 Tips extra

- Puedes iniciar el servidor con:
    
    `php artisan serve`
    
- Si deseas regenerar los assets:
    
    `npm run build`
    
- Para crear nuevos componentes Livewire:
    
    `php artisan make:livewire NombreComponente`
