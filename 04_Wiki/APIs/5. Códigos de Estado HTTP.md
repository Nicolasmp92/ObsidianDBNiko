# 📬 Códigos de Estado HTTP

Cada respuesta de una API REST devuelve un **código de 3 dígitos** que indica qué pasó con la petición. El verbo dice qué quisiste hacer; el código dice qué pasó.

## Las 5 familias

| Rango | Significa | Lectura rápida |
|---|---|---|
| **1xx** | Informativo | Raro en APIs |
| **2xx** | Éxito | Todo salió bien |
| **3xx** | Redirección | El recurso se movió |
| **4xx** | Error del cliente | La petición está mal |
| **5xx** | Error del servidor | El servidor falló |

## ✅ 2xx — Éxito

| Código | Cuándo |
|---|---|
| `200 OK` | Consulta o actualización exitosa (GET, PUT, PATCH) |
| `201 Created` | Se creó un recurso nuevo (respuesta típica de POST) |
| `204 No Content` | Éxito sin cuerpo de respuesta (típico de DELETE) |

## ↩️ 3xx — Redirección

| Código | Cuándo |
|---|---|
| `301 Moved Permanently` | El recurso cambió de URL para siempre |
| `302 Found` | Redirección temporal |
| `304 Not Modified` | Nada cambió desde la última vez (caché) |

## ⚠️ 4xx — Error del cliente

| Código | Cuándo |
|---|---|
| `400 Bad Request` | Petición malformada |
| `401 Unauthorized` | Falta autenticación (no estás logueado) |
| `403 Forbidden` | Autenticado pero sin permiso |
| `404 Not Found` | El recurso no existe |
| `422 Unprocessable Content` | Datos válidos en forma, inválidos en contenido → **errores de validación de Laravel** |
| `429 Too Many Requests` | Rate limit excedido |

## 💥 5xx — Error del servidor

| Código | Cuándo |
|---|---|
| `500 Internal Server Error` | Excepción no controlada (tu error 500 de siempre) |
| `502 Bad Gateway` | Un servicio intermedio falló (nginx → fpm) |
| `503 Service Unavailable` | Servidor caído o en mantenimiento |

## 🎯 Regla REST práctica

> **Verbo + URI + Código = respuesta completa.** Ejemplos coherentes:
> - `POST /usuarios` → `201 Created` (no `200`)
> - `DELETE /usuarios/5` → `204 No Content`
> - `GET /usuarios/999` inexistente → `404 Not Found`
> - Validación fallida en Laravel → `422` con los errores en JSON
