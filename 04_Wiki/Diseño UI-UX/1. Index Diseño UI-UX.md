# 📐 Index — Diseño UI / UX

Base de conocimiento sobre diseño de interfaces (UI), experiencia de usuario (UX) y las metodologías de desarrollo de este ámbito (mobile-first, atomic design, design systems, research, accesibilidad). Línea de investigación y aprendizaje — nivel introductorio, con foco práctico en nuestros proyectos web (Angular/CSS). Orden sugerido de lectura: el número del archivo.

## Entradas

- [[2. Patrones mobile-first - stacked layout, boton fijo, sticky CTA y thumb zone]] — Los 4 términos fundacionales del diseño móvil orientado a acción: qué significan, cómo se implementan en CSS y qué dice la investigación real (Hoober).
- [[3. Composicion de vistas moviles - anatomia de pantalla y donde va cada boton]] — El vocabulario para describir una vista: 5 regiones (app bar, body, FAB, bottom bar, overlays) + reglas de jerarquía que asignan cada botón a su región. Mapea 1:1 con el Scaffold de Flutter.

## Por escribir (cola)

- Mobile-first y responsive design: breakpoints, `min-width` vs `max-width`, container queries
- Atomic Design (Brad Frost): atoms → molecules → organisms → templates → pages
- Design systems y tokens: variables CSS, componentes reutilizables
- Jerarquía visual y patrones de escaneo (F, Z), los 8pt grid
- Touch targets y accesibilidad (WCAG 2.2, safe-area, focus visible)
- UX research básico: tests de usabilidad, heurísticas de Nielsen
- Formularios móviles: teclado correcto por input, validación, errores
