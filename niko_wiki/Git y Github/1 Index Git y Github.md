🧭 Introducción al Control de Versiones

El control de versiones es el sistema que te permite viajar en el tiempo dentro de tu código.

- **[[Git]]**: La herramienta técnica que vive en tu terminal.
- **[[GitHub]]**: El hogar de tus proyectos en la nube para colaborar y respaldar.

> [!ABSTRACT] Resumen  
> **Git** gestiona el historial; **GitHub** lo aloja y potencia con herramientas sociales.

---

🛠️ Entorno y Herramientas

Para dominar Git, necesitas un lugar donde escribir y herramientas que te asistan.

- **La Terminal**: Es el puente de mando. Yo recomiendo **Git Bash** para evitar problemas de compatibilidad.
- **Asistentes**: Herramientas como [[GitHub Copilot]] para programar con IA o [[GitHub Desktop]] para quienes buscan una interfaz visual.

Para saber cómo dejar todo listo, visita: 📂 **[[2 Instalación y Configuración Inicial]]**

🔄 Flujo de Trabajo y Ciclo de Vida

Trabajar en Git es un ciclo constante de: _Observar -> Preparar -> Guardar -> Compartir_. Seguir un orden lógico evita que pierdas código o pises el trabajo de otros.

Para profundizar en el flujo diario y aprender los comandos esenciales, ve a:  
👉 **[[Comandos de Git y Flujo de Trabajo]]**

🌿 Organización de Ramas

Para que el historial de tu proyecto no sea un drama (o un "espagueti" de líneas sin sentido), es vital separar las tareas. No todo se sube a la misma rama; se divide por funcionalidades, correcciones o mejoras.

Para aprender a nombrar tus ramas como un profesional y mantener el orden, consulta:
