## ⌨️ Comandos Esenciales de Docker: La Hoja de Trucos

Para dominar Docker no hace falta saberse los cientos de flags que existen, sino entender el ciclo de vida de los objetos (Imágenes, Contenedores y Volúmenes).

### 1. Gestión de Contenedores (El día a día)

Estos comandos controlan las instancias que están "vivas" o detenidas.

- **Listar contenedores activos:** `docker ps`
    
- **Listar TODOS los contenedores (incluso los apagados):** `docker ps -a`
    
- **Detener un contenedor:** `docker stop [ID_o_Nombre]`
    
- **Eliminar un contenedor:** `docker rm [ID_o_Nombre]`
    

### 2. Gestión de Imágenes (Las plantillas)

- **Ver imágenes descargadas en mi PC:** `docker images`
    
- **Descargar una imagen sin ejecutarla:** `docker pull [nombre_imagen]` (ej: `docker pull php:8.3-fpm`)
    
- **Borrar una imagen:** `docker rmi [ID_Imagen]`
    

### 3. Entrando a "las entrañas" del contenedor

Como desarrollador Laravel, muchas veces necesitarás entrar al contenedor para ejecutar comandos de Artisan o Composer.

- **Acceder a la terminal del contenedor:** `docker exec -it [nombre_contenedor] bash` _(Si el contenedor es Alpine Linux, usa `sh` en lugar de `bash`)._
    
- **Ver logs en tiempo real:** `docker logs -f [nombre_contenedor]` (Ideal para debuggear errores 500).
    

### 4. Limpieza Profunda (Mantenimiento)

Docker tiende a acumular "basura" (imágenes huérfanas, volúmenes sin uso) que llenan el disco duro rápidamente.

- **Limpiar todo lo que no se esté usando:** `docker system prune`
    
- **Limpiar incluyendo volúmenes (¡Cuidado! Borra bases de datos locales):** `docker system prune -a --volumes`
